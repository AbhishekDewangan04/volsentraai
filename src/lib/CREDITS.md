# Visual effects and attribution

Volsentra's visual effects in `src/components/fx` and `src/components/common` are local project components. The motion primitives use the existing Framer Motion dependency; chart rendering uses the existing Recharts dependency; iconography uses the existing Lucide React dependency. No third-party registry snippets or paid assets were added for this change, so no new attribution is required.

The requested references to React Bits, 21st.dev and ThreeUI were treated as visual direction only. Their proprietary source code was not copied.
